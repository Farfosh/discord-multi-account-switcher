Security

Designed so there's nothing to steal

Most "multi-account" tools ask you to paste a token. This one never does, and it can't read your Discord pages at all.

What it does

  • Starts Chrome with a separate profile folder for each account.
  • Opens only fixed Discord addresses: the login page or an invite page.
  • Stores names, tags, and tiny pictures in a local file on your PC.
  • Refuses to delete a profile that is still open or that points somewhere else.

What it never does

  • Ask for, read, store, log, or inject Discord tokens.
  • Run scripts on Discord or read your messages. It has no content scripts.
  • Click Join Server, bypass CAPTCHA, or call Discord's API.
  • Send anything over the internet. There is no server.

Read the full model in SECURITY.md. Every release lists SHA-256 checksums so you can verify the download.

FAQ

Common questions

Why is there a Windows helper?

Chrome extensions can't start Chrome with a different profile folder. The small helper does only that, and Chrome lets only this extension talk to it. It accepts a short list of fixed actions and never takes URLs, file paths, or commands from the extension.

Windows shows "Windows protected your PC". Is that normal?

The helper isn't code-signed, so SmartScreen may warn about it. Unblocking the zip before extracting (step 1) usually avoids the prompt. You can compare the file's SHA-256 with the checksum listed on the release page before running it.

Does it copy the account I'm already signed in to?

No. Each profile starts empty and you sign in inside its own window. Chrome keeps that login in the profile, so next time it opens already signed in.

Why isn't it on the Chrome Web Store?

It needs the local helper to launch Chrome profiles, so it's installed with Developer mode and a fixed extension ID that the helper trusts. Chrome may remind you that a developer-mode extension is on; that's expected.

What happens when I delete a profile?

Deleting is available after archiving. It removes the profile and its Chrome folder from your PC, including the saved login. It doesn't sign that session out on Discord's servers; use User Settings → Devices in Discord for that.

How do I uninstall?

Run scripts\uninstall-native-host.cmd, then remove the extension from chrome://extensions. Your profile list is kept in case you reinstall. Delete profiles from the popup first if you want their data gone.
